# Microsoft Store listing — English (United States)

## Product name

TabbyBBMonitor

## Short description

Monitor Bluetooth device battery levels from the system tray and receive Windows notifications at per-device thresholds.

## Description

TabbyBBMonitor is a lightweight system-tray utility that monitors battery levels reported by Bluetooth and Bluetooth Low Energy devices paired with Windows.

It periodically checks compatible mice, keyboards, headphones, pens, and other devices whose battery levels are exposed by Windows. Set Critical, Low, and Caution thresholds for each device and receive a Windows notification when a battery crosses one of those thresholds.

Key capabilities

• View monitored Bluetooth devices and their current battery levels
• Configure three notification thresholds for each device
• Receive Windows notifications when battery status changes
• Choose a check interval from 10 to 3,600 seconds
• Set shared default thresholds for newly discovered devices
• Search, rediscover, and clean up unavailable device settings
• Optionally start the app when you sign in
• Use the interface in any of 18 supported languages

Privacy

No account is required. The app contains no advertising or analytics and does not transmit device information or settings to an external server. Bluetooth device information and preferences are processed only on your Windows device.

Compatibility

The app can display only devices that are paired with Windows and whose device or driver reports a battery level to Windows. Some devices may not expose a level while disconnected and may appear as “Battery level unknown.”

Supported OS: Windows 10 version 2004 or later, and Windows 11.
