Windows向け通知領域アプリ

Bluetooth機器の電池切れを、早めに気づけるように

TabbyBBMonitorは、Windowsが取得した機器の電池残量を定期的に確認します。状態は通知領域のアイコンで確認でき、設定したしきい値をまたぐと通知を受け取れます。

Microsoft Storeで入手 ユーザーマニュアルを開く
電池状態 68%
注意 Bluetooth機器

機器ごとの状態を、通知領域からすぐ確認できます。

確認間隔 既定30秒
通知しきい値 機器ごとに3段階
自動起動 必要な場合のみ有効化

主な機能

01

通知領域で状態を確認

アプリを開いたままにせず、電池状態をアイコンと右クリックメニューから確認できます。

02

しきい値をまたいだら通知

危険・低下・注意のしきい値を設定し、状態が変化したときにWindowsの通知を表示します。

03

機器ごとに個別設定

監視のオン／オフやしきい値を機器ごとに調整し、必要な機器だけを監視できます。

04

定期確認と手動更新

10～3600秒の確認間隔を選べるほか、「今すぐ確認」で必要なときに更新できます。

03

3つのステップ

使い始めるまで

  1. 機器をWindowsとペアリング

    WindowsのBluetooth設定で、監視したい機器をペアリングします。

  2. 初回画面で監視対象を確認

    アプリを起動すると機器を自動検索します。監視する機器と自動起動の設定を確認します。

  3. 通知領域から状態を確認

    「監視を開始」を選ぶと、アプリが通知領域に常駐して確認を始めます。

詳しい操作を確認する

インストール、初期設定、設定画面の使い方はユーザーマニュアルで確認できます。

ユーザーマニュアルを開く

利用できるBluetooth機器

Windowsとペアリング済みで、機器またはドライバーが電池残量をWindowsへ公開している機器が対象です。機器によっては残量を取得できない場合があります。
