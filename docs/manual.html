はじめに

Bluetooth機器の電池残量を、通知領域から確認する

TabbyBBMonitorは、Windowsが取得したBluetooth機器の電池残量を監視し、状態の変化を通知する常駐アプリです。このページでは、インストールから日常の使い方までを順に案内します。

対応OS Windows 10 バージョン2004以降 / Windows 11
対象機器 Windowsとペアリング済みのBluetooth機器
01

まずアプリを準備します

インストール手順

  1. Microsoft Storeの商品ページを開く

    下のボタンからTabbyBBMonitorの商品ページを開きます。

    Microsoft Storeで入手

  2. アプリをインストールする

    商品ページで「入手」または「インストール」を選択します。

  3. アプリを起動する

    インストール完了後に「開く」を選択すると、初期設定が始まります。

追加のランタイムは不要です

Microsoft Store版には動作に必要なファイルが含まれています。別途.NET Desktop Runtimeをインストールする必要はありません。

02

初回だけ行います

初期設定手順

  1. 自動検索が終わるまで待つ

    初回起動では「ようこそ」画面が開き、ペアリング済みのBluetooth機器を自動的に検索します。「検出中...」の表示が変わるまで待ちます。

  2. 監視する機器を確認する

    検出された機器を選択し、「このデバイスを監視する」が有効になっていることを確認します。監視しない機器はチェックを外せます。

  3. 必要に応じて自動起動を選ぶ

    「サインイン時に自動起動する」は既定でオフです。Windowsへのサインイン後も自動で監視したい場合だけ有効にします。

  4. 監視を開始する

    「監視を開始」を選択すると設定が保存され、アプリが通知領域に常駐します。

機器が見つからない場合

「Bluetooth設定を開く」からWindowsの設定を確認し、機器をペアリングしてください。機器が0台でも監視を開始でき、あとから「再検出」できます。

設定を中断した場合

初回画面で「キャンセル」を選ぶか画面を閉じると、設定を保存せずアプリを終了します。次回起動時に初期設定がもう一度表示されます。

03

セットアップ後の操作

使用手順

通知領域

電池状態を確認する

タスクバーの通知領域にあるアイコンが、監視中の電池状態を示します。Windows 11で見えない場合は、タスクバー右端の隠しアイコンを開いてください。

右クリックメニュー

必要な操作をすぐ実行する

「今すぐ確認」で電池情報を更新できます。「設定...」で設定画面を開き、「終了」でアプリを終了します。アイコンのダブルクリックでも設定画面を開けます。

デバイスタブ

機器ごとに監視方法を調整する

監視のオン／オフ、通知のしきい値、機器の再検出を設定できます。選択したしきい値をすべての機器へ一括適用することもできます。

全般タブ

アプリ全体の動作を変更する

確認間隔、通知、自動起動、表示言語、新しく検出する機器の初期しきい値を変更できます。確認間隔は10～3600秒で、既定は30秒です。

既定の設定

電池状態のしきい値

残量がしきい値をまたぐと通知します。しきい値は機器ごとに変更できます。

状態 既定の残量 目安
危険 0～15% すぐに充電してください
低下 16～35% 充電を準備してください
注意 36～70% 残量を確認してください
良好 71～100% 十分な残量があります

変更する場合は「危険 < 低下 < 注意」の順になるよう設定してください。

対応機器について

監視できるのは、Windowsとペアリング済みで、機器またはドライバーが電池残量をWindowsへ公開しているBluetooth機器だけです。対応していても未接続時には「残量不明」になる場合があります。
