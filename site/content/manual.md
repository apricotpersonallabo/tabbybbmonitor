# TabbyBBMonitor ユーザーマニュアル

現在の本番マニュアルは、移行完了まで `docs/manual.html` を正とします。

## 対応環境

Windows 10 バージョン2004以降、およびWindows 11を対象とします。監視対象はWindowsとペアリング済みで、Windowsへ電池情報を公開しているBluetooth機器です。

## インストール

1. [Microsoft Storeの商品ページ](https://apps.microsoft.com/detail/9mzb7986z2rn)を開きます。
2. 「入手」または「インストール」を選択します。
3. インストール後にアプリを起動します。

Microsoft Store版には必要なランタイムが含まれるため、別途.NET Desktop Runtimeを導入する必要はありません。

## 初期設定

1. 初回起動時の自動検索が完了するまで待ちます。
2. 検出された機器から監視対象を確認します。
3. 必要な場合のみサインイン時の自動起動を有効にします。
4. 「監視を開始」を選択します。

機器が見つからない場合はWindowsのBluetooth設定でペアリング状態を確認してください。

## 日常の操作

通知領域のアイコンから電池状態を確認できます。右クリックメニューでは「今すぐ確認」、設定画面の表示、終了などを実行できます。

設定画面では、機器ごとの監視、有効なしきい値、再検出、確認間隔、通知、自動起動、表示言語などを変更できます。

## アプリの更新

Microsoft Store版は起動時に更新を確認します。更新通知をクリックすると「ヘルプ」が開きます。「ヘルプ」の「更新をチェック」から手動で確認することもできます。

更新がある場合は「更新する」を選択して承認すると、Microsoft Store経由でダウンロード・インストールします。進捗は画面に表示します。アプリが終了する場合があるため、設定変更は先に保存してください。インストール要求中は設定画面を閉じられません。キャンセルや失敗時は監視を続け、再試行できます。更新後は必要に応じてアプリを起動し直してください。

起動時に最新版だった場合や確認に失敗した場合は通知しません。状態はヘルプで確認できます。通常exe実行版やテスト署名版は非対応です。

## 既定のしきい値

- 危険: 0～15%
- 低下: 16～35%
- 注意: 36～70%
- 良好: 71～100%

しきい値は機器ごとに変更できます。変更時は危険 < 低下 < 注意の順になるよう設定してください。
